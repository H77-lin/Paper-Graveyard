01 / Organize

Build your own index.

Create and rename categories, then add subcategories at any level. Green marks the first level; yellow marks the next. Topics and tags connect papers across folders.

02 / Record

Write as you read.

Open the local library to add papers, source links, abstracts and private reading notes. Save writes to a file on this computer. Your work is still here when you reopen the library.

03 / Keep

A library for yourself.

Use Back up for a complete private JSON copy. Automatic backups are made before each save. Public export includes only papers you explicitly approve, and excludes private notes and reading status.

Original paper titles and abstracts keep their source language. Imported AI summaries are marked for verification. A source link may lead to a publisher page rather than free full text.
